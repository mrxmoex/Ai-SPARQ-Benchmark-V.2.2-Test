# Contributing to SPARQ

Thank you for your interest in contributing to the SPARQ project! Whether you're fixing bugs, improving documentation, or adding new features, we're excited to have you on board.

## How to Contribute

1. **Fork the Repository**  
   Click the 'Fork' button in the upper right corner of the repository to create your own copy of the project.

2. **Clone Your Fork**  
   Use the following command to clone the forked repository to your local machine:  
   ```bash
   git clone https://github.com/YOUR_USERNAME/Ai-SPARQ-Benchmark-V.2.2-Test.git
   ```

3. **Create a New Branch**  
   It's a good practice to create a new branch for your changes:  
   ```bash
   git checkout -b your-feature-name
   ```

4. **Make Changes**  
   Make your changes or additions to the codebase.

5. **Run Tests**  
   Ensure that all existing and new tests pass. You can run tests using:  
   ```bash
   pytest
   ```

6. **Commit Your Changes**  
   Commit your changes with a descriptive commit message:  
   ```bash
   git commit -m "Descriptive message of your changes"
   ```

7. **Push to Your Fork**  
   Push your changes to your forked repository:  
   ```bash
   git push origin your-feature-name
   ```

8. **Open a Pull Request**  
   Go to the original repository and click on the 'New Pull Request' button to propose your changes.

## Running Tests

To ensure the stability of the code, make sure to run the test suite before submitting your pull request. To run the tests, execute the following command in your terminal:
```bash
pytest
```

If you have any questions, feel free to reach out in the Issues section of the repository! We're here to help.

Happy contributing!
